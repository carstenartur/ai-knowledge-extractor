# 0.2.0 release notes

Release date: 2026-08-31

## Highlights

- language-neutral source provider SPI;
- experimental JavaScript, JSX, TypeScript and TSX structural extraction;
- JDT-backed Spring and JAX-RS endpoint extraction;
- frontend/client to Java/backend boundary linking;
- explainable boundary dimensions and dependency-surface evidence;
- schema-v2 source-unit, symbol, relation, boundary and warning artifacts;
- shared repository scan policy for Gradle, Maven and core callers;
- published-marker and plugin-goal consumer verification;
- deterministic release-readiness and documentation checks.

## Compatibility and migration

This is a minor pre-1.0 release with additive artifacts and a clarified public provider contract.
Consumers that deserialize JSON strictly must allow the new schema-v2 fields and files. Existing
Java artifacts remain available.

JavaScript/TypeScript analysis is experimental in 0.2.x. Inspect `provider`, `confidence`,
`complexityProvider` and `complexityAccuracy` before using a finding as a quality gate.

The common source policy is configured through `aiknowledge.source.*` JVM properties. Integrators
should review [`../integrator-quickstart.md`](../integrator-quickstart.md), and provider authors
should review [`../provider-spi.md`](../provider-spi.md) and
[`../schema-v2-contract.md`](../schema-v2-contract.md).

## Distribution

The audited release workflow publishes version 0.2.0 to:

- GitHub Releases, including the built JARs and a `SHA256SUMS` manifest;
- GitHub Packages, including Core, Sources, Javadocs, the Gradle plugin marker and the Maven plugin.

GitHub Packages is the binary integration channel for this release and requires package-read
credentials. Version 0.2.0 is **not** published to Maven Central or the Gradle Plugin Portal. See
[`../publishing.md`](../publishing.md) for repository and credential configuration.

## Deliberate exclusions

The release reads the current checkout only. Git commit history, co-change matrices and
commit-derived change coupling are not implemented and do not contribute to any score.
