# 0.2.0 release notes (target)

## Highlights

- language-neutral source provider SPI;
- experimental JavaScript, JSX, TypeScript and TSX structural extraction;
- JDT-backed Spring and JAX-RS endpoint extraction;
- frontend/client to Java/backend boundary linking;
- explainable boundary dimensions and dependency-surface evidence;
- schema-v2 source-unit, symbol, relation, boundary and warning artifacts;
- shared repository scan policy for Gradle, Maven and core callers.

## Compatibility and migration

This is a minor pre-1.0 release with additive artifacts and a clarified public provider contract.
Consumers that deserialize JSON strictly must allow the new schema-v2 fields and files. Existing
Java artifacts remain available.

JavaScript/TypeScript analysis is experimental in 0.2.x. Inspect `provider`, `confidence`,
`complexityProvider` and `complexityAccuracy` before using a finding as a quality gate.

## Publication status

A tag must not claim Maven Central availability until the release workflow has successfully staged,
signed and resolved the Core, Gradle plugin marker and Maven plugin from Central. Until then the
README and release page must name the actual repository used for the artifacts.

## Deliberate exclusions

The release reads the current checkout only. Git commit history, co-change matrices and
commit-derived change coupling are not implemented and do not contribute to any score.
