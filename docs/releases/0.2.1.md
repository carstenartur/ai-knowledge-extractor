# 0.2.1 release candidate

Status: prepared for review; not published. Active schema-v2 line: `main`.

## Changes since 0.2.0

- Prune ignored repository subtrees before inventory traversal.
- Complete schema-v1 to v2 migration guidance and executable mixed-language/provider consumer contracts.
- Add opt-in boundary policies, failure evidence, HTML reports and reproducible eleven-scenario corpus evaluation.
- Normalize context-debt trend gating and reject duplicate or incompatible providers before artifact writes.
- Support separate active and maintenance release lines with exact-head verification of generated metadata follow-ups.
- Rehearse signed public distribution with disposable keys and clean consumers.

## Compatibility and distribution

Schema-v2 remains the active contract. JavaScript/TypeScript extraction remains experimental.
Review [schema migration](../schema-v2-migration.md) before regenerating retained outputs or baselines.
The 0.1.x maintenance line retains schema-v1 and is released separately.

GitHub Releases and authenticated GitHub Packages remain the established channels.
Maven Central and Gradle Plugin Portal publishing is opt-in and requires real account setup,
publication and remote consumer evidence. Successful rehearsal does not establish public availability.

The extractor reads the current checkout; Git history, co-change matrices and commit-derived
change coupling are outside this release.
